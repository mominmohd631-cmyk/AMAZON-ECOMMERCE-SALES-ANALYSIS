# AMAZON-ECOMMERCE-SALES-ANALYSIS
# 🛒 Amazon E-commerce Sales Analysis

### Data Analytics Portfolio Project | Excel • MySQL • Power BI

## 📌 Project Overview

This project focuses on analyzing approximately **12,000 e-commerce records** to understand sales performance, order distribution, product categories, and fulfilment operations.

The objective is to transform raw data into meaningful insights using Microsoft Excel, MySQL, and Power BI, and present the findings through interactive dashboards and SQL-based analysis.

## 🎯 Business Objectives

- Evaluate overall sales performance and average order amount.
- Analyze order status and fulfilment patterns.
- Identify top-performing shipping cities and product categories.
- Understand order distribution across different business dimensions.
- Build dashboards to support data-driven decision-making.

## 🧰 Tools & Technologies

| Tool | Purpose |
|---|---|
| Microsoft Excel | Data cleaning, Pivot Tables, charts, and dashboard |
| MySQL | SQL queries, aggregations, grouping, and analysis |
| Power BI | Data visualization and interactive reporting |

## 📊 Key Analysis Performed

### 1. Data Cleaning — Excel
- Checked and prepared the dataset for analysis.
- Worked with missing values and data formatting.
- Used Pivot Tables, charts, and dashboard components.

### 2. SQL Analysis — MySQL
- Counted total records.
- Analyzed sales amount and average order amount.
- Examined order status and fulfilment distribution.
- Identified the top 10 shipping cities.
- Analyzed product categories and order sizes.

### 3. Dashboard Development
- Created an Excel dashboard with KPI cards and charts.
- Developed a Power BI dashboard for visual analysis.
- Presented sales trends, order distribution, and fulfilment information.
